# Banking sistem
> **Last Update:** 13.07.2026 | **Verison:** v1.0.0

Banking system CLI is programmed in C++ programming language. Project like this is very good for programmers who are new to Object-Oriented-Programming (OOP) techniques. For anyone looking to expand their brand new portfolio and dive deeper into the programming in C++ I highly suggest to try and build something like this. Project like this is very dynamic, because you can program it in wither normal way (functions, I/O) or using Object-Oriented-Programming, therefore my point being is two programmers can write the same program in a different way of coding in the same programming language.

# Features
* New account creation
* Money/fund deposit on account
* Money/fund withdrawing from account
* Printout of all accounts

## Used Technology
* **Programming Language:** C++
* **Tools:** Visual Studio Code
* **Packaging and compiling:** GCC/G++

## How to launch/start the project
To use the project and test it you must have a compiler such as MinGW or Visual Studio compiler, otherwise you will not be able to complie the code into .exe (executable) and test the code.

# Repositroy cloning command (cmd, terminal, powershell)
git clone https://github.com/dzenan-batakovic/banking-app-cpp.git

# Map entering
cd banking-app-cpp

# Compiler command
g++ *.cpp -o "Banka.exe" -static -static-libgcc -static-libstdc++
